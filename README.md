# NorthStar Logistics — standalone site

This is a self-contained, single-file logistics concept page. The HTML includes
its own styles and JavaScript; it has no build step, package dependencies, or
backend service.

## Run locally

Open `index.html` in a browser, or serve this folder with any static file
server.

## Included interactions

- Displays example European and U.S. freight shipments and driver assignments.
- Updates the displayed clock and example arrival estimates every second.
- Lets visitors look up one of the sample shipment IDs.
- Highlights Greece and Athens as a regional coordination hub.

All shipment statuses, names, counts, and allocations are fictional examples.
The clock is current, but the site is not connected to real carrier, GPS,
dispatch, or customer data.
